---
title: Install the Arduino IDE
summary: Get the tools onto your machine.
---

Download and install the Arduino IDE for your operating system from the offline
installer your instructor provided.

On Linux you can also use the package script:

```bash
# Extract and run the bundled installer
tar -xf arduino-ide.tar.xz
cd arduino-ide && ./install.sh
```

Once installed, launch it. You should see an empty sketch with `setup()` and `loop()`.

When the IDE opens cleanly, you're done here.
